# Zaduzenja

Aplikacija za porudžbine u ribarnici (Android 7.0 ili noviji).

## Preuzimanje

Najnovija verzija je uvek ovde:
**https://github.com/Sogli031/zaduzenja/releases/latest**

Pod „Assets" preuzmi fajl `zaduzenja-app-vX.Y.apk`.

## Instalacija

1. Otvori preuzeti `.apk` fajl (iz obaveštenja ili iz aplikacije „Fajlovi" → „Preuzimanja").
2. Telefon će javiti da je instalacija iz nepoznatih izvora blokirana. Dodirni **Podešavanja** i uključi **Dozvoli iz ovog izvora** za aplikaciju iz koje otvaraš fajl (Chrome, Fajlovi…).
3. Vrati se nazad i dodirni **Instaliraj**.
4. Ako se pojavi upozorenje Google Play zaštite, izaberi **Više detalja → Ipak instaliraj**.

## Nove verzije

Nova verzija se instalira preko postojeće i svi podaci ostaju sačuvani.

Ne briši aplikaciju pre ažuriranja, jer se time brišu i podaci.

## Obtainium (automatsko ažuriranje)

Ako koristiš [Obtainium](https://github.com/ImranR98/Obtainium/releases/latest):

1. U Obtainium-u dodirni **Add App**.
2. U polje **App Source URL** upiši: `https://github.com/Sogli031/zaduzenja`
3. Dodirni **Add**. Obtainium preuzima i instalira najnoviju verziju.
4. Ubuduće će te Obtainium obavestiti kad izađe nova verzija, a ažuriraš jednim dodirom.
